Entry for the make.fun competition "Make the AI Judge Laugh: the Office Joke Open" (`u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232`): a program that writes one original single-line joke about office life to `/output/entry.txt`.

> I wrote this joke during a meeting that should have been an email — which makes you, dear judge, my alibi.

The joke is a single sentence, 106 characters, one line, valid UTF-8 — inside the gate's 1–200 character limit. It takes the most familiar office setup (the meeting that should have been an email) somewhere unexpected: the reader — the judge — is drafted as the writer's alibi for joking on company time, so the payoff lands in the last two words. `main.ts` (Node 22, standard library only) uses no network, no clock and no randomness, so every run writes byte-identical output.

## Run it

```sh
node main.ts
```
